Invite codes

Each code lets one person join. Codes can't be looked up again later, so give a code out when you make it.

    People

    Link a device makes a code that adds a device, such as a computer, to that person's account. It works once and lasts a day, and appears under Invite codes.

      Transcripts

      Names and words the phones and computers should expect when they write out messages, such as a name that sounds like a common word. Separate them with commas. Everyone in People and every group are included already. While there are any, iPhones transcribe with Apple's dictation model, the one that can favor them, in place of its newer speech model.

      Echo

      Echo is a built-in contact that sends back any clip it receives, the quickest check that recording, push and playback work. Hiding it removes it from everyone's contacts along with their messages with it.
